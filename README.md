# Current-Buffer-Amplifier
Designed and simulated a Current Buffer Compensated Op-Amp using transistor-level CMOS design. Achieved 85.3 dB DC gain, 22.3 MHz unity-gain bandwidth, 60.6° phase margin, 20.84 V/µs slew rate, and low power dissipation, with performance verified through Cadence Virtuoso simulations.
